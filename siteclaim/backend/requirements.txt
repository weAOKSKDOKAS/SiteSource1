# pytesseract==0.3.13
#   Local OCR of scanned tender pages (pipeline/ocr.py), imported LAZILY.
#
#   INSTALL IT ONLY TOGETHER WITH THE SYSTEM `tesseract` BINARY
#   (apt-get install tesseract-ocr / the UB-Mannheim installer on Windows, then
#   point TESSERACT_CMD at it if it is not on PATH).
#
#   The three states are not equivalent, and the middle one is a misconfiguration:
#     - neither installed        -> OCR unavailable; scanned pages degrade to vision. Green.
#     - both installed           -> OCR reads scanned pages as text. Green.
#     - package WITHOUT binary   -> pipeline/ocr.py raises OcrEngineUnavailable LOUDLY by
#                                   design (it is a config fault, never silently swallowed),
#                                   which fails 7 tests in test_documents.py / test_doc_index.py.
#   That loud failure is correct behaviour, not a bug — but it means this line must not be
#   uncommented on a machine that has no tesseract binary.
